Тест ростехнадзор — PWA для iPhone, версия 2

Файлы:
- index.html — приложение и вопросы
- manifest.webmanifest — параметры установки
- sw.js — офлайн-работа
- icon.png — иконка

Логика прогресса:
- правильный ответ добавляет вопрос в выученные;
- неправильный ответ удаляет вопрос из выученных и добавляет в ошибки;
- после изучения всех вопросов начинается новый случайный круг;
- полный прогресс не сбрасывается при начале нового круга.

Разместите все файлы на HTTPS-хостинге, откройте сайт в Safari и выберите «На экран Домой».
